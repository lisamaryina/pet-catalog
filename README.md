# Pet Catalog 🐾

Вебсторінка-каталог домашніх тварин, створена в межах навчального завдання.

## Можливості

- Перегляд карток тварин з фото та описом
- Пошук і фільтрація тварин
- Адаптивний дизайн для телефона та комп'ютера

## Технології

- HTML
- CSS
- JavaScript
